# BMZ — Беларуская МуЗыка

Каталёг беларускай музыкі, якую можна спампаваць легальна: выканаўцы, іхныя
альбомы й трэкі, і месцы, дзе кожны альбом можна купіць або спампаваць
бясплатна. Зарэгістраваныя карыстальнікі ацэньваюць і камэнтуюць музыку і
пазначаюць, што ёсьць у іхнай калекцыі.

## Галоўнае правіла

Ніякага пірацтва. Сайт спасылаецца толькі на месцы, якія выбраў сам выканаўца
або ягоны лейбл, і паказвае, дзе спампаваньне бясплатнае, дзе — «заплаці,
колькі хочаш», а дзе трэба купіць.

## Стан

Распрацоўваецца. Гатова: база каталёгу, імпарт з `BY.txt`, імпарт і экспарт
JSON, API для чытаньня.

## Патрабаваньні

- Java 21
- Docker — для PostgreSQL падчас распрацоўкі і тэстаў

## Запуск

```bash
cd backend
./mvnw test             # тэсты
./mvnw spring-boot:run  # сэрвэр на http://localhost:8080
```

Пры запуску Spring Boot сам падымае PostgreSQL у Docker з `compose.yaml`.

Імпарт з `BY.txt` і экспарт у JSON за адзін запуск:

```bash
./mvnw spring-boot:run -Dspring-boot.run.arguments="--bmz.import.by-txt=BY.txt --bmz.export.json=catalogue.json"
```
