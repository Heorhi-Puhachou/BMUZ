# BMZ — Беларуская МуЗыка

Каталёг беларускай музыкі, якую можна спампаваць легальна: выканаўцы, іхныя
альбомы й трэкі, і месцы, дзе кожны альбом можна купіць або спампаваць
бясплатна. Зарэгістраваныя карыстальнікі ацэньваюць і камэнтуюць музыку і
пазначаюць, што ёсьць у іхнай калекцыі.

## Галоўнае правіла

Ніякага пірацтва. Сайт спасылаецца толькі на месцы, якія выбраў сам выканаўца
або ягоны лейбл, і паказвае, дзе спампаваньне бясплатнае, дзе — «заплаці,
колькі хочаш», а дзе трэба купіць.

## Стан

Распрацоўваецца. Гатова: каталёг з супольнымі альбомамі, імпарт з `BY.txt`,
імпарт і экспарт JSON, API для чытаньня, старонкі выканаўцаў і альбомаў,
пошук.

## Склад

| Тэчка       | Што                                         |
| ----------- | ------------------------------------------- |
| `backend/`  | Java 21, Spring Boot, PostgreSQL            |
| `frontend/` | React, TypeScript, Vite                     |
| `data/`     | каталёг у JSON — пачатковыя дадзеныя        |

## Патрабаваньні

- Java 21
- Node.js 22
- Docker — для PostgreSQL падчас распрацоўкі і тэстаў

## Запуск для распрацоўкі

У адным тэрмінале — бэкэнд:

```bash
cd backend
./mvnw test             # тэсты
./mvnw spring-boot:run  # сэрвэр на http://localhost:8080
```

Пры запуску Spring Boot сам падымае PostgreSQL у Docker з `compose.yaml`.

У другім — старонкі:

```bash
cd frontend
npm install
npm run dev             # http://localhost:5173
```

Імпарт каталёгу ў пустую базу:

```bash
./mvnw spring-boot:run -Dspring-boot.run.arguments="--bmz.import.json=../data/catalogue.json"
```

## Вобраз Docker

Бэкэнд і старонкі разам, як на сэрвэры:

```bash
docker build -t bmz .
```
