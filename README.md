# BMUZ — Беларуская МУЗыка

Сайт: **[bmuz.eu](https://bmuz.eu)**

Каталёг беларускай музыкі, якую можна спампаваць легальна: выканаўцы, іхныя
альбомы й трэкі, і месцы, дзе кожны альбом можна купіць або спампаваць
бясплатна. Зарэгістраваныя карыстальнікі ацэньваюць і камэнтуюць музыку і
пазначаюць, што ёсьць у іхнай калекцыі.

## Галоўнае правіла

Ніякага пірацтва. Сайт спасылаецца толькі на месцы, якія выбраў сам выканаўца
або ягоны лейбл, і паказвае, дзе спампаваньне бясплатнае, дзе — «заплаці,
колькі хочаш», а дзе трэба купіць.

## Стан

Распрацоўваецца. Гатова: каталёг з супольнымі альбомамі, імпарт з `BY.txt`,
імпарт і экспарт JSON, API для чытаньня, старонкі выканаўцаў і альбомаў,
пошук, тры правапісы — тарашкевіца, афіцыйны і łacinka, уваход і ролі,
праўка каталёга адміністратарамі й выканаўцамі, вокладкі, `sitemap.xml`.
Сайт працуе на AWS і выкладаецца праз GitHub Actions.

## Склад

| Тэчка       | Што                                         |
| ----------- | ------------------------------------------- |
| `backend/`  | Java 21, Spring Boot, PostgreSQL            |
| `frontend/` | React, TypeScript, Vite                     |
| `data/`     | каталёг у JSON — пачатковыя дадзеныя        |
| `infra/`    | як сайт працуе на AWS                       |
| `.github/`  | выкладка праз GitHub Actions                |

## Патрабаваньні

- Java 21
- Node.js 22
- Docker — для PostgreSQL падчас распрацоўкі і тэстаў

## Запуск для распрацоўкі

У адным тэрмінале — бэкэнд:

```bash
cd backend
./mvnw test             # тэсты
./mvnw spring-boot:run  # сэрвэр на http://localhost:8080
```

Пры запуску Spring Boot сам падымае PostgreSQL у Docker з `compose.yaml`.

У другім — старонкі:

```bash
cd frontend
npm install
npm run dev             # http://localhost:5173
```

Імпарт каталёгу ў пустую базу:

```bash
./mvnw spring-boot:run -Dspring-boot.run.arguments="--bmuz.import.json=../data/catalogue.json"
```

## Правапісы

Тэксты старонак пішуцца толькі ў `frontend/src/messages/tar.json`.
Афіцыйны правапіс і łacinka робяцца з іх праграмай
[orthography-converter](https://github.com/Heorhi-Puhachou/orthography-converter),
сабранай побач з гэтым рэпазыторыем:

```bash
cd frontend
npm run messages
```

Словы, якія праграма канвэртуе няправільна, выпраўляюцца ў `overrides.json`.

## Вобраз Docker

Бэкэнд і старонкі разам, як на сэрвэры:

```bash
docker build -t bmuz .
```
